MY MONEY — ANDROID INSTALL

1. On GitHub, create a new PUBLIC repository, for example my-money.
2. Choose Add file > Upload files and upload the FIVE FILES INSIDE this ZIP (not the ZIP itself, and not the enclosing folder).
3. In repository Settings > Pages, choose Deploy from a branch, main, / (root), then Save.
4. Wait for the GitHub Pages link to become available. Open it in Chrome on the Android phone.
5. Chrome menu (three dots) > Add to Home screen > Install.

PRIVACY: GitHub Pages publishes the app code publicly, but the records are saved in this browser on this device, not in GitHub. Records do not sync between devices. Use the app backup feature regularly and keep backup files safe. Clearing browser data, switching browsers, or uninstalling may erase records. Use only one URL for the app: opening the old HTML file and the hosted app gives separate storage.
